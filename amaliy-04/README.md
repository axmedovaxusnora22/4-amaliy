# MahallaMarket — 4-amaliy ish

## Loyiha mavzusi
MahallaMarket — kundalik ehtiyoj mahsulotlarini ko‘rsatadigan namunaviy onlayn savdo platformasi.

## Ishga tushirish
1. `amaliy-04` papkasini Visual Studio Code orqali oching.
2. `index.html` faylini Live Server orqali ishga tushiring.
3. Menyu orqali Bosh sahifa, Mahsulotlar va Aloqa sahifalariga o‘ting.

## Qo‘shilgan imkoniyatlar
- Mahsulotlar massivini JavaScript orqali yaratish.
- Mahsulot kartalarini DOM orqali chiqarish.
- Mahsulot nomi bo‘yicha qidiruv.
- Kategoriya bo‘yicha filtr.
- Narx va nom bo‘yicha saralash.
- Mahsulotlar soni va statistika.
- Batafsil modal oynasi.
- Event delegation.
- Aloqa formasini tekshirish.
- Tungi rejim va tanlovni localStorage da saqlash.

## Massiv metodlari
- `map` — `js/data.js` faylida mahsulot nomlari massivini olish.
- `filter` — `js/data.js` faylida mavjud mahsulotlarni ajratish va `js/katalog.js` faylida qidiruv/kategoriya filtri.
- `reduce` — `js/data.js` va `js/katalog.js` fayllarida narxlar yig‘indisini hisoblash.
- `sort` — `js/data.js` faylida hamda `js/katalog.js` faylida saralash.
- `find` — `js/data.js` va `js/katalog.js` fayllarida kerakli mahsulotni topish.

## Eslatma
Aloqa formasi hozircha ma'lumotni serverga yubormaydi; u faqat brauzerda maydonlarni tekshiradi va muvaffaqiyat xabarini ko‘rsatadi.
